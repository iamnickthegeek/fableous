# Test Results Log

## How to Use This File

After running each test, append a new entry. This is the living record of what works.

---

## Template Entry

```markdown
### Date: [YYYY-MM-DD]

**Test:** [T1 / T2 / etc]
**Task:** [Description]
**Result:** [PASS / FAIL]
**Details:** [What happened]
**Adjustments:** [What was changed in the skill]
```
