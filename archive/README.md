# Archive

This folder contains old Fable Orchestrator code and documents that are no longer
used by v6. They are kept for reference only.

- `v5-engine/` — The v5 Python engine (`fable_engine/`), daemon, v3 orchestrator,
  setup helpers, tests, and v5-era reference documents.
- `v4/` — The v4 orchestrator script and v4 notes.
- `planning/` — Early v6 planning documents, including the native-tools-first audit
  and implementation plan.

Do not use these files for new work. The current version lives in the repository
root (`SKILL.md`, `references/`, `templates/`, `scripts/`, `examples/`).
